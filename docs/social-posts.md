# Social media posts for ಆಟ–ಪಾಠ · Aata–Paata

Drafts for the seven features of the games page. Link to use: `https://karnata.sanchaya.net/#aata-paata`
(or `https://try-karnata.sanchaya.net/#aata-paata` when the live site is down). Each game also has a direct link, for
example `...?game=where#aata-paata`; the game names are `word`, `year`, `crossword`, `where`, `who`, `script`,
`worksheet`.

The Kannada is a draft written without a native speaker and **needs proofreading before posting**. Nothing here has
been posted. The clues come from atlas records, many of which are still awaiting review, so every post invites
corrections.

Suggested hashtags: #ಕರ್ನಾಟಕ #ಕನ್ನಡ #ಇತಿಹಾಸ #ಆಟಪಾಠ #KarnatakaHistory #Kannada #HistoryGames #Sanchaya

## 1. ಪದಯಾನ · Word Trail (`?game=word`)

**ಕನ್ನಡ**
ಇಂದಿನ ಪದ ಯಾವುದು? 🟩🟨⬛ ಆರು ಪ್ರಯತ್ನ, ಒಂದು ಕನ್ನಡ ಪದ — ರಾಜವಂಶ, ಸ್ಥಳ, ಕೃತಿ ಅಥವಾ ಶಾಸನದ ಹೆಸರು.
ಅಕ್ಷರದ ಬದಲು ಕನ್ನಡದ ಅಕ್ಷರ ಘಟಕಗಳೇ ಚೌಕಗಳು! ನಿಮ್ಮ ಫಲಿತಾಂಶ ಹಂಚಿಕೊಳ್ಳಿ, ಉತ್ತರ ಹೇಳಬೇಡಿ 🤫

**English**
Today's word: six tries, one Kannada word, the name of a dynasty, place, work or inscription. 🟩🟨⬛
Each tile is a real Kannada letter unit, not a code point. Share your grid, not the answer. 🤫

**Challenge variant (EN):** Stuck at try 4? The hint tells you what kind of record it is. By try 5 you get the first letter.

## 2. ಕಾಲಚೌಕ · Time Grid (`?game=year`)

**ಕನ್ನಡ**
ಸುಡೊಕು ಇಷ್ಟವೇ? ಇದು ಇತಿಹಾಸದ ಸುಡೊಕು! 🔢 ನಾಲ್ಕು ಐತಿಹಾಸಿಕ ವರ್ಷಗಳನ್ನು ಪ್ರತಿ ಸಾಲು, ಅಂಕಣ ಮತ್ತು 2×2 ಚೌಕದಲ್ಲಿ ಒಮ್ಮೆ ಮಾತ್ರ ಇರಿಸಿ.
ಮುಗಿದ ಮೇಲೆ ಆ ವರ್ಷಗಳ ಹಿಂದಿನ ಘಟನೆಗಳನ್ನು ನೋಡಿ.

**English**

the atlas events behind those years.

**ಕನ್ನಡ**
ಈ ವಾರದ ಪದಜಾಲ ಸಿದ್ಧ! ✏️ ರಾಜವಂಶ, ಸ್ಥಳ, ಕೃತಿ, ಶಾಸನ ಮತ್ತು ನಿಸರ್ಗದ ಸುಳಿವುಗಳು. ಕನ್ನಡ ಟೈಪಿಂಗ್ ಕಷ್ಟವೇ? ಧ್ವನ್ಯಾತ್ಮಕ ಕೀಲಿಮಣೆ ಇದೆ.
ಒಂದು ಅಕ್ಷರದ ಸಹಾಯ ಬೇಕಾದರೆ "ಒಂದು ಅಕ್ಷರ ತೋರಿಸಿ" ಒತ್ತಿ.

**English**

Kannada? There is a phonetic keyboard built in, and a "reveal one letter" button when you need it.

## 4. ಎಲ್ಲಿದೆ? · Where is it? (`?game=where`)

**ಕನ್ನಡ**
ನಕ್ಷೆಯಲ್ಲಿ ಹಿರೀಸಾವೆ ಎಲ್ಲಿದೆ? 📍 ಐದು ಐತಿಹಾಸಿಕ ಸ್ಥಳ, ಒಂದು ಗುರುತು. ಹತ್ತಿರವಿದ್ದಷ್ಟೂ ಹೆಚ್ಚು ಅಂಕ — 400 ಕಿ.ಮೀ. ದೂರವಾದರೆ ಸೊನ್ನೆ!
ನಿಮ್ಮ ಅಂಕ ಎಷ್ಟು? ನಮ್ಮ ಅಂಕವನ್ನು ಮೀರಿಸಬಲ್ಲಿರಾ?

**English**
Can you point to Hirisave on the map? 📍 Five historical places a day, one pin each. The closer you are, the more
points: 1000 on the spot, zero at 400 km. Post your score and challenge a friend.

**Result-share style (EN):** `Aata–Paata · Where is it? 1823/5000 🟩🟨🟥🟥🟥`

## 5. ನಾನು ಯಾರು? · Who am I? (`?game=who`)

**ಕನ್ನಡ**
ನಾನು ಯಾರು? 🤔 ಸುಳಿವು 1: ಸುಮಾರು 1156–1184 ಕ್ರಿ.ಶ.ರಲ್ಲಿ ಸಕ್ರಿಯ. ಸುಳಿವು 2: ರಾಜಧಾನಿ ಕಲ್ಯಾಣ…
ಕಡಿಮೆ ಸುಳಿವಿನಲ್ಲಿ ಸರಿ ಹೇಳಿದರೆ ಹೆಚ್ಚು ಅಂಕ. ಉತ್ತರ ಕಾಮೆಂಟ್‌ನಲ್ಲಿ ಬೇಡ, ಅಂಕ ಮಾತ್ರ ಹೇಳಿ!

**English**
Who am I? 🤔 Clue 1: active about 1156–1184 CE. Clue 2: capital at Kalyana… Name the dynasty with as few clues as
you can: 4 points on clue one, 1 point on clue four. Keep the answer out of the comments; just post your score.

## 6. ಲಿಪಿ ಪತ್ತೆದಾರ · Script Detective (`?game=script`)

**ಕನ್ನಡ**
ಈ ಅಕ್ಷರ ಶೈಲಿ ಯಾವ ಕಾಲದ್ದು? 🔍 ಕದಂಬ, ಗಂಗ, ಚಾಲುಕ್ಯ, ಹೊಯ್ಸಳ — ಒಂದೇ ಕನ್ನಡ ಪದ ಬೇರೆ ಬೇರೆ ಕಾಲದ ಅಕ್ಷರ ಶೈಲಿಯಲ್ಲಿ ಹೇಗೆ ಕಾಣುತ್ತದೆ ಎಂದು ಗುರುತಿಸಿ.
(ಇವು ಆ ಕಾಲದ ಶೈಲಿಯನ್ನು ಸ್ಮರಿಸುವ ಇಂದಿನ ಮುದ್ರಣ ಅಕ್ಷರಗಳು.)

**English**
Which era's lettering is this? 🔍 The same Kannada word in Kadamba, Ganga, Chalukya and Hoysala styles: can you tell
them apart? (These are modern typefaces that recall each period's lettering, not readings of an inscription.)

**ಕನ್ನಡ**
ಶಿಕ್ಷಕರೇ, ಇದು ನಿಮಗಾಗಿ! 🏫 ಇಂದಿನ ಆಟಗಳ ಮುದ್ರಿಸಬಹುದಾದ ಕಾರ್ಯಪತ್ರ — ಸ್ಥಳಗಳು, ರಾಜವಂಶಗಳು, ಲಿಪಿ ಶೈಲಿಗಳು. ಉತ್ತರಗಳು ಕೊನೆಯ ಪುಟದಲ್ಲಿ.
ಒಂದು ಕ್ಲಿಕ್‌ನಲ್ಲಿ ಮುದ್ರಿಸಿ, ತರಗತಿಯಲ್ಲಿ ಬಳಸಿ.

**English**
Teachers, this one is for you. 🏫 A printable worksheet of the day's places, dynasties and script styles, with the
answer key on the last page. Print it and use it in class.

## Share images

`scripts/share-cards/` makes one 1080x1080 image per post above, in Kannada and in English (16 files:
`launch`, `word`, `year`, `crossword`, `where`, `who`, `script`, `worksheet`, each as `.kn.png` and `.en.png`).
Edit the text and illustrations in `cards.mjs`, then:

```bash
npm i --no-save playwright && npx playwright install chromium
node scripts/share-cards/generate.mjs output/share-cards
```

If Playwright is installed elsewhere, point `PLAYWRIGHT` at its `index.mjs`. The images are ignored by git. The
Kannada text on them is a draft and needs proofreading before posting; the example scores, words and clues are
illustrations, not a real day's puzzle.
