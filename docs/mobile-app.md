# Mobile apps (Android and iOS)

The atlas is wrapped with [Capacitor](https://capacitorjs.com) so the same web build can go to Google Play and the Apple App Store. The apps ship the **static edition** (`VITE_STATIC_DATASET=true`): the published dataset is bundled inside the app, there is no sign-in, admin, contribution form or visit tracking, and it works offline. That also keeps the store reviews simple (no account deletion or user-content moderation needed).

## Files

- `capacitor.config.json`: app id `net.sanchaya.karnata`, name "Karnataka Atlas", web folder `dist-app`. **The app id cannot be changed after the first store upload; change it now if you want another.**
- `android/` and `ios/`: the native projects generated by Capacitor (commit them).
- `dist-app/`: the app's web build (ignored by git).

## Commands

```sh
npm run app:sync      # build the static edition into dist-app and copy it into both native projects
npm run app:android   # sync, then open Android Studio
npm run app:ios       # sync, then open Xcode
```

Run `npm run app:sync` after every web change you want in the apps.

## Before the first store upload (not done yet)

- **Icons and splash screens** are still Capacitor's defaults. Make them from `public/icon-512.png` (for example with `@capacitor/assets`).
- **Android:** install Android Studio (SDK and an emulator), open `android/`, create the upload keystore, build a signed App Bundle (.aab). A personal Play account created after November 2023 needs a closed test with about 12 testers for 14 days before production.
- **iOS:** open `ios/App/App.xcodeproj`, set the signing team and bundle id, archive, and upload through Xcode Organizer or Transporter to App Store Connect. Apple may reject an app that is only a website; the offline dataset, share links and the games help, but add something native if review pushes back (for example sharing a record, or a home-screen widget later).
- **Donate:** Apple restricts payment links inside iOS apps; consider hiding the Donate section in the app build.
- **Map tiles:** OpenStreetMap's public tile servers do not allow heavy app traffic; use a licensed or self-hosted tile source before release.
- **Store listing:** privacy policy URL, Play data-safety form and Apple App Privacy answers (the static edition collects nothing), screenshots in Kannada and English, and the non-commercial description.
- **Checked here:** the iOS project builds for the simulator (`xcodebuild`, signing off). **Not checked:** running it on a simulator or phone (no simulator runtime installed), and any Android build (no Android SDK installed).
